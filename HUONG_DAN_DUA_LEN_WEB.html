Soát Văn Bản AI v1.0.3 — triển khai Vercel

Quan trọng: bản ShopAIKey phải giữ OPENAI_BASE_URL=https://api.shopaikey.com/v1. Không dùng endpoint api.openai.com với key ShopAIKey.

1. Biến môi trường bắt buộc

OPENAI_API_KEY=sk-...
APP_ACCESS_CODE=...
UPSTASH_REDIS_REST_URL=...
UPSTASH_REDIS_REST_TOKEN=...

2. Model khuyến nghị

OPENAI_FAST_MODEL=gpt-5.4-nano-2026-03-17
OPENAI_QUALITY_MODEL=gpt-5.6-terra-ultra
OPENAI_HIGH_RISK_LOCAL_MODEL=gpt-5.4-nano-2026-03-17
OPENAI_LOCAL_MODEL=gpt-5.4-nano-2026-03-17
OPENAI_LOCAL_FALLBACK_MODEL=gpt-5.4-nano-2026-03-17
OPENAI_HIGH_RISK_MODEL=gpt-5.6-terra-ultra
OPENAI_DEEP_MODEL=gpt-5.4-nano-2026-03-17
OPENAI_DEEP_FALLBACK_MODEL=gpt-5.4-nano-2026-03-17
OPENAI_LEGAL_FAST_MODEL=gpt-5.4-nano-2026-03-17
OPENAI_LEGAL_RELATION_MODEL=gpt-5.6-terra-ultra
OPENAI_LEGAL_MODEL=gpt-5.6-terra-ultra
OPENAI_LEGAL_FALLBACK_MODEL=gpt-5.4-nano-2026-03-17
AI_HIGH_RISK_PROFILES=administrative,contract,academic
LEGAL_SEARCH_DOMAINS=vanban.chinhphu.vn,datafiles.chinhphu.vn,congbao.chinhphu.vn,vbpl.vn,moj.gov.vn
AI_LOCAL_TIMEOUT_MS=55000
AI_DEEP_TIMEOUT_MS=75000
AI_LEGAL_TIMEOUT_MS=45000

3. Kiểm tra trước khi deploy

npm install
npm run typecheck
npm run build

4. Đưa lên GitHub/Vercel

  1. Thay source cũ bằng thư mục v1.0.3.
  2. Commit và push lên repository đang kết nối với Vercel.
  3. Trong Vercel → Project → Settings → Environment Variables, cập nhật các biến ở trên.
  4. Redeploy Production.
  5. Kiểm thử bằng tệp Duthao Quychephoihop NQ205(1).docx hoặc ca trong tests/QUALITY_REGRESSION.md.
Model routing v1.0.3: LOCAL dùng GPT-5.4 nano; GLOBAL dùng Terra chỉ cho văn bản rủi ro cao; LEGAL dùng Nano cho metadata và tự nâng Terra cho quan hệ sửa đổi/bổ sung/thay thế/bãi bỏ. Sol không chạy tự động. Cảnh báo pháp lý chỉ được giữ nếu có nguồn chính thức.

5. Tiêu chí kiểm thử quan trọng

Đoạn viện dẫn Nghị định 29/2025/NĐ-CP cùng Nghị định 109/2025/NĐ-CP và 166/2025/NĐ-CP phải được đưa vào lượt LEGAL review nhưng không được báo sai chỉ vì trích yếu Nghị định 109 nói về Thanh tra Chính phủ. Lượt LEGAL phải kiểm tra toàn văn/điều khoản tác động; Điều 4 khoản 3 của Nghị định 109 có sửa/bãi bỏ một số nội dung của Nghị định 29.
