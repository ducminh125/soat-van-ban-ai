Đưa Soát Văn Bản AI v0.8 lên Vercel

Điểm khác v0.7: v0.8 cần Redis bền vững để quản lý quota 30 văn bản/ngày và thống kê ngày/tháng/năm/tổng.

1. Đưa mã nguồn v0.8 lên repository

Upload toàn bộ thư mục v0.8. Các file mới quan trọng gồm:

app/api/usage/route.ts
lib/usage.ts
CAP_NHAT_V0_8.html

Các file đã thay đổi gồm app/page.tsx, app/globals.css, app/api/review/route.ts, lib/ai.ts, lib/docx-client.ts, lib/types.ts, package.json, .env.example và README.md.

2. Cài dependency

npm install
npm run typecheck
npm run build
Sau khi npm install thành công, nên commit file package-lock.json được tạo ra để deployment có dependency reproducible.

3. Tạo Redis

  1. Tạo Redis database trên Upstash hoặc dùng Upstash integration trong Vercel.
  2. Lấy REST URL và REST token.
  3. Đặt hai biến môi trường UPSTASH_REDIS_REST_URL và UPSTASH_REDIS_REST_TOKEN.

Nếu integration cung cấp KV_REST_API_URL và KV_REST_API_TOKEN, v0.8 cũng tự nhận hai tên này.

4. Environment Variables cần thiết

OPENAI_API_KEY=...
OPENAI_BASE_URL=https://api.shopaikey.com/v1
APP_ACCESS_CODE=...

UPSTASH_REDIS_REST_URL=...
UPSTASH_REDIS_REST_TOKEN=...

DAILY_DOCUMENT_LIMIT=30
USAGE_TIME_ZONE=Asia/Bangkok
USAGE_KEY_PREFIX=soat-van-ban-ai:v0.8
REVIEW_RESERVATION_TTL_SECONDS=10800
REVIEW_REQUESTS_PER_MINUTE=120

OPENAI_LOCAL_MODEL=gpt-5.4-mini-2026-03-17
OPENAI_LOCAL_FALLBACK_MODEL=gpt-5.1-2025-11-13
OPENAI_DEEP_MODEL=gpt-5.6-sol
OPENAI_DEEP_FALLBACK_MODEL=gpt-5.1-2025-11-13
NEXT_PUBLIC_AI_CONCURRENCY=4
AI_LOCAL_FIRST_BYTE_TIMEOUT_MS=80000
AI_DEEP_FIRST_BYTE_TIMEOUT_MS=115000
AI_STREAM_IDLE_TIMEOUT_MS=45000
AI_LOCAL_MAX_TOKENS=2600
AI_DEEP_MAX_TOKENS=3200
APP_ACCESS_CODE là bắt buộc ở v0.8. Nếu thiếu, API từ chối hoạt động thay vì bỏ qua xác thực.

5. Redeploy

  1. Commit/push source.
  2. Vào Vercel → Project → Settings → Environment Variables và nhập đủ biến trên.
  3. Redeploy.
  4. Mở trang chủ và xác nhận góc phải hiển thị Review Workspace · v0.8.
  5. Kiểm tra dashboard có số lượt còn lại, thống kê và đồng hồ đếm ngược.

6. Test quota

  1. Đặt tạm DAILY_DOCUMENT_LIMIT=2 trên một môi trường test.
  2. Rà soát hoàn tất hai file.
  3. Xác nhận lượt còn lại về 0 và nút chọn/bắt đầu review bị khóa.
  4. Đổi lại DAILY_DOCUMENT_LIMIT=30 và redeploy.

7. Test chỉnh cảnh báo

Chọn một mục Cảnh báo nội dung. Dù AI không có replacement, ô nhập vẫn xuất hiện. Nhập nội dung thay thế, bấm Chấp nhận nội dung đã chỉnh, rồi tải Word và kiểm tra.

8. Test xuất Word

Sau khi tải, v0.8 sẽ báo số thay đổi áp dụng thành công/thất bại và số thay đổi đi qua nhiều Word run cần kiểm tra định dạng.

Khuyến nghị: test trên Preview Deployment trước khi đưa lên Production, đặc biệt với file có header/footer, footnote và định dạng chữ đậm/nghiêng xen kẽ.
