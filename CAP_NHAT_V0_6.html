Cập nhật Soát Văn Bản AI lên v0.6 — Parallel Review

Mục tiêu: tăng tốc bằng cách rà soát tối đa 4 phần đồng thời bằng model nhanh/cân bằng, sau đó dùng model mạnh cho một lượt kiểm tra nhất quán toàn văn.

1. Các file cần thay trên GitHub

Trong repository hiện tại, thay các file sau bằng file v0.6:

lib/ai.ts
lib/types.ts
app/api/review/route.ts
app/page.tsx

Các file dưới đây không bắt buộc để app chạy nhưng nên cập nhật để đồng bộ:

.env.example
package.json
README.md
CAP_NHAT_V0_6.html

2. Cập nhật biến môi trường trên Vercel

Vào Vercel → Project → Settings → Environment Variables.

Giữ nguyên:

OPENAI_API_KEY = key ShopAIKey của bạn
OPENAI_BASE_URL = https://api.shopaikey.com/v1
APP_ACCESS_CODE = mã truy cập của bạn

Thêm hoặc sửa:

OPENAI_LOCAL_MODEL = gpt-5.4-mini-2026-03-17
OPENAI_LOCAL_FALLBACK_MODEL = gpt-5.1-2025-11-13
OPENAI_DEEP_MODEL = gpt-5.6-sol
OPENAI_DEEP_FALLBACK_MODEL = gpt-5.1-2025-11-13
NEXT_PUBLIC_AI_CONCURRENCY = 4
Biến cũ OPENAI_REVIEW_MODEL và OPENAI_FALLBACK_MODEL của v0.5 không còn được v0.6 dùng. Có thể để lại hoặc xóa.

3. Redeploy

  1. Commit các file trên GitHub.
  2. Vào Vercel → Deployments.
  3. Chờ deployment mới hoặc chọn Redeploy.
  4. Mở website và kiểm tra góc phải có dòng Parallel Review · v0.6.

4. v0.6 hoạt động thế nào?

Word
 ↓
Chia thành nhiều phần
 ↓
4 worker chạy song song bằng gpt-5.4-mini
 ↓
Mỗi worker trả lỗi + dữ kiện cần đối chiếu
 ↓
Gộp toàn bộ dữ kiện
 ↓
gpt-5.6-sol kiểm tra mâu thuẫn toàn văn
 ↓
Gộp kết quả → duyệt lỗi → xuất Word

5. Nếu ShopAIKey báo nhiều 429 hoặc 524

Đầu tiên giảm số luồng song song:

NEXT_PUBLIC_AI_CONCURRENCY = 2

Save rồi Redeploy. Khi ổn định có thể thử 3 hoặc 4.

6. Cách biết rà soát đủ

Ứng dụng chỉ hiển thị thông báo hoàn tất khi:

  • Tất cả local batch đều đã thành công.
  • Lượt kiểm tra toàn văn đã hoàn thành, hoặc tài liệu không có fact cần đối chiếu.

Nếu một request bị 524/5xx, app retry và có thể chia phần nhỏ hơn; không tự coi phần đó là hoàn tất.

Sau khi cập nhật: thử trước với file Word 3–10 trang. Nếu lỗi, gửi nguyên thông báo lỗi và ảnh màn hình phần tiến độ; không gửi API key.
