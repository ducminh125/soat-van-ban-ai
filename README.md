# Soat Van Ban AI v1.0

Ung dung Next.js + OpenAI + Supabase de ra soat file Word.

## Deploy Vercel

1. Upload ma nguon len Github.
2. Import repository vao Vercel.
3. Khai bao Environment Variables:

OPENAI_API_KEY
OPENAI_MODEL
SUPABASE_URL
SUPABASE_ANON_KEY
SUPABASE_SERVICE_KEY
NEXT_PUBLIC_APP_NAME

4. Deploy.
