Cập nhật v0.7 Review Workspace

Nếu bạn đang dùng v0.6: chỉ cần thay 2 file trên GitHub. Không cần đổi API key, model hay Environment Variables.

1. Thay các file

app/page.tsx
app/globals.css

Trong GitHub, mở từng đường dẫn, tải file mới lên thay file cũ và Commit changes.

2. Chờ Vercel deploy

Vercel thường tự deploy sau khi GitHub có commit mới. Nếu chưa, vào Deployments và chọn Redeploy.

3. Kiểm tra đúng phiên bản

Mở website. Góc trên phải phải hiện Review Workspace · v0.7.

Điểm mới

  • Đồng hồ thời gian đã chạy theo thời gian thực.
  • Ước tính thời gian còn lại theo tốc độ thực tế.
  • Danh sách lỗi có bộ lọc trạng thái và loại lỗi.
  • Mỗi lần tập trung vào một lỗi để dễ quyết định.
  • Tô nổi lỗi ngay trong đoạn văn.
  • So sánh nội dung hiện tại với đề xuất cạnh nhau.
  • Nút Trước, Sau, Chấp nhận, Bỏ qua.
  • Sau khi xử lý một lỗi, giao diện chuyển sang lỗi kế tiếp.
